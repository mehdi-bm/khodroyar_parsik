# خودرویار پارسیک

اپ فارسی مدیریت خودرو با Flutter، پایگاه داده محلی Drift، گزارش شمسی، یادآوری سرویس و مدارک و پشتیبان همراه عکس.

## اجرا و ساخت

```powershell
flutter pub get
flutter run --dart-define-from-file=.secrets/ads.json
./tool/build_android.ps1
```

راهنمای امضا، تنظیمات تبلیغات و ساخت آزمایشی در [راهنمای انتشار بازار](docs/BAZAAR_RELEASE.md) قرار دارد. ساخت بدون تنظیمات تبلیغ، بنر و فرم‌های آنلاین را غیرفعال می‌کند؛ برای خروجی قابل انتشار از اسکریپت بالا استفاده کنید.

## بررسی

```powershell
$env:NO_PROXY='localhost,127.0.0.1,::1'
flutter analyze
flutter test
```

متغیر NO_PROXY از عبور اتصال محلی تست از پراکسی جلوگیری می‌کند.

- [گزارش اصلاحات تجربه کاربری](docs/UX_REVIEW_FA.md)
- [متن پیشنهادی صفحه بازار](docs/STORE_LISTING_FA.md)
- [تست‌ها و تصاویر بررسی](artifacts/)

کلید امضا و تنظیمات خصوصی را به مخزن عمومی اضافه نکنید. فونت وزیرمتن به‌صورت محلی همراه مجوز OFL عرضه می‌شود.
